# BBC Symphony Orchestra Discover: installed palette

Checked 16 November 2026 against Spitfire's current product page, edition comparison and untuned-percussion guide. Spitfire advertises 34 instruments; percussion groups and playing variants are not 34 separate plugin presets. The current product page says 47 techniques; the support comparison says 48, so do not treat that headline count as a verified local patch count.

| Family | Included instruments |
|---|---|
| Strings | First violins, second violins, violas, cellos, double basses. These are sections, not solo strings. |
| Woodwinds | Piccolo; flutes a3; oboes a3; clarinets a3; bassoons a3. |
| Brass | Horns a4; trumpets a2; tenor trombones a3; bass trombones a2; tuba. The current product page and installed trumpet preset say a2; an older support list says a3. |
| Keyboard / tuned instruments | Concert grand piano (Steinway Model D), harp, celeste, timpani, marimba, xylophone, glockenspiel, tubular bells. |
| Untuned percussion | Bass drum, tenor drum, snare drum, suspended cymbal, suspended cymbal roll, anvil, tam-tam, tambourine, tenor drum with snares off, triangle, castanets, cowbell, stopped cymbal, piatti, vibraslap and woodblock. These are keyboard-mapped sounds within a percussion patch. |

Strings have Long (vibrato), spiccato and pizzicato. Violins, violas and cellos also have tremolo; basses do not list it. Woodwinds and brass have Long and staccatissimo. Default MIDI controls: CC1 dynamics, CC11 expression, CC19 reverb, CC7 gain, CC10 pan. Discover has one dynamic layer per technique, no recorded legato and no round-robin sample alternation.

## Quartet implications

VPO supplies playable solo violin, viola and cello sounds locally, so solo availability is no longer the only gap. The user explicitly prefers BBC's sound quality after comparing the renders. BBC uses a consistent professional studio recording and orchestra; VPO combines free sources. The dry VPO mix, its sample/envelope limitations and the automated score interpretation also affect the comparison. More controls do not upgrade the underlying recordings.

Use the BBC quartet arrangement template when that sound is preferred, accepting that it is a string-section arrangement of quartet music. Use VPO for economical solo workflow/prototyping. A higher-quality solo string library with recorded legato and expressive dynamic layers remains a separate acquisition/audition decision. No paid library has been purchased. BBC Core adds depth and solo winds/brass but does not provide the string leader set; those leaders are listed under Professional. Do not buy Core expecting a solo quartet.
